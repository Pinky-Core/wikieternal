# 🏹 Sistema de kits



## <mark style="color:blue;">¿Dónde cargo mis kits?</mark>

Aquí es donde podrás cargar tus kits en los marcos.

<figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

## <mark style="color:blue;">¿Cómo guardo mi kit?</mark>

Para guardar un kit debes de tener las cosas que vas a guardar y luego debes de usar <mark style="color:purple;">**/kit save \[nombre]**</mark>

## <mark style="color:blue;">**¿Cómo cargo mi kit?**</mark>

Antes de cargar un kit, asegúrate de haber guardado tu kit como anteriormente explicado. Bien para cargarlo usa <mark style="color:purple;">**/kit load \[nombre]**</mark>

## <mark style="color:blue;">**¿Como elimino mi kit?**</mark>

Para eliminar un kit usa <mark style="color:purple;">**/kit delete \[nombre]**</mark>

## <mark style="color:blue;">**¿Cómo edito mi kit?**</mark>

Para editar un kit debes de cargar tu <mark style="color:purple;">**/kit load \[nombre]**</mark> y modificar lo que desees y luego <mark style="color:purple;">**/kit save \[nombre exacto del otro]**</mark>
