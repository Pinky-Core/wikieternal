# ⚔️ Duels

## <mark style="color:#9000df;">¿Como se manda un duelo?</mark>

Para mandar un duelo usa <mark style="color:purple;">**/duel \[nombre]**</mark>

## <mark style="color:#9000df;">¿Como se acepta un duelo?</mark>

Puedes usar el comando <mark style="color:purple;">**/duel accept \[nombre]**</mark> o <mark style="color:purple;">**/duel deny \[nombre]**</mark>

## <mark style="color:#9000df;">¿Como entro en una cola de duels?</mark>

Recuerda tener el kit cargado

Ve al npc que dice <mark style="color:purple;">**''RTP QUEUE''**</mark> y a esperar el contratincante.
